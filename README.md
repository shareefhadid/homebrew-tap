# shareefhadid/homebrew-tap

Homebrew formulae for [shareefhadid](https://github.com/shareefhadid)'s tools.

```sh
brew install shareefhadid/tap/csb
```

| Formula | Description |
| ------- | ----------- |
| [`csb`](https://github.com/shareefhadid/csb) | Sandboxed Claude Code on Apple `container` |

Formulae here are updated automatically by each project's release workflow.
